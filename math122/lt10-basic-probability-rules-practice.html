Basic Probability Rules

I can use complement, addition, and multiplication rules to calculate probabilities involving “not,” “or,” and “and,” using tables or diagrams when helpful.

Quick Review: Probability Rules

Complement
\(P(A^c)=1-P(A)\)
Addition (“or”)
\(P(A\cup B)=P(A)+P(B)-P(A\cap B)\)
Multiplication (“and”)
\(P(A\cap B)=P(A)P(B\mid A)\)
Independent events
\(P(A\cap B)=P(A)P(B)\)

Special cases: Mutually exclusive events have \(P(A\cap B)=0\). For “at least one,” use \(1-P(\text{none})\). When sampling without replacement, update the probabilities after each draw.
