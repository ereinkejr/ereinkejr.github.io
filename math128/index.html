Welcome to Math 128

Math 128 introduces the basic ideas and tools of data analytics and data science. The course emphasizes understanding data, preparing data for analysis, using computational tools, and communicating conclusions clearly.

We will use Python and Google Colab for computational work. No previous programming experience is assumed.

Course Focus

The course develops practical data skills while emphasizing the reasoning behind the methods.

  • Understanding data
  • Data preparation
  • Data analysis
  • Visualization
  • Communication

Course Topics

Understanding Data

Populations and samples, observational units, variables, structured data, tidy data, and metadata.

Data Wrangling

Cleaning, transforming, reshaping, and combining datasets.

Data Analysis

Descriptive, diagnostic, predictive, and prescriptive approaches to answering questions with data.
