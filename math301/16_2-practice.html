Quick Reference

Independent events
One event occurring does not change the probability of the other.
Independent-event rule
\(P(A\text{ and }B)=P(A)\cdot P(B)\).
Multiplication rule
For any two events, \(P(A\text{ and }B)=P(A)\cdot P(B\mid A)\).
Dependent events
The occurrence of one event changes the probability of the other. For example, drawing cards without replacement.
Expected value
Multiply each numerical outcome by its probability, then add the products.
\[ E=n_1p_1+n_2p_2+\cdots+n_rp_r \]

For expected-value problems, use the net gain or loss for each outcome. Make sure the probabilities add to 1.

Independent or Dependent?

Independent: Tossing a coin and rolling a die. The coin result does not affect the die result.

Dependent: Drawing two cards from a deck without replacement. The first card changes the number of cards remaining for the second draw.

When events are dependent, use the probability of the second event given that the first event occurred.

Interpreting Expected Value

Expected value is a long-run average outcome over many repetitions of an experiment. A negative expected value represents an average loss to the player; a positive expected value represents an average gain.

For a game with a win and a loss, calculate the expected value using the net amounts won or lost, not simply the amount paid out.
