Quick Reference

Function
A function assigns exactly one output to each input. We write \(y=f(x)\).
Linear function
\(f(x)=mx+b\), where \(m\) is the rate of change and \(b=f(0)\) is the initial value.
Rate of change
For two points, \(m=\dfrac{y_2-y_1}{x_2-x_1}\), provided \(x_1\ne x_2\).
Recognizing linearity
Equal changes in input must produce equal changes in output.
Proportional relationship
A proportional linear relationship has the form \(y=mx\), so its initial value is \(0\).
Arithmetic sequences
\(a_n=a_1+(n-1)d\). Plotting \((n,a_n)\) gives points on a line, but only integer inputs are used.

Connecting Sequences and Linear Functions

An arithmetic sequence has a constant difference \(d\). Its terms can be written as

\[a_n=a_1+(n-1)d=dn+(a_1-d).\]

This is the same rule as a linear function evaluated at the positive integers. The sequence is discrete: its graph consists of individual points \((n,a_n)\), rather than every point along a continuous line.
